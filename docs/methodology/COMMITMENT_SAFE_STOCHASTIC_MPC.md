# Commitment-Safe Stochastic MPC — formulation

**Proposed method (single controller):** commitment-safe RH MPC with SPI-over-greedy selection,
accept discipline (M1–M4), **family-fit** multi-scenario demand, **stratified** finite-demand
scenarios, **MSA consensus** first-action selection (Bent & Van Hentenryck), and
**adaptive_compute_v1** (`CommitmentSafeStochasticMpc` + `load_family_forecasts(family)`).
Same MPC class on all datasets; priors are never silently reused across families.

**Baselines (paper names):**

- Economic MPC — greedy nominal scoring
- Full-validation ALNS–MPC
- Certificate-carrying ALNS–MPC
- Scenario economic MPC (sampled futures)

**Ablations:** empty-future; mean-score SAA (no MSA); cross-family (wrong) priors; proposed without SPI; linear-charge planning vs nonlinear plant.

Objective weights (fixed):

- `SERVICE_REWARD = 100`
- `UNFULFILLED_PENALTY = 250`
- `DISTANCE_PENALTY = 1`

---

## 1. Mathematical program (ideal)

At event epoch \(t\), with public state \(x_t\) and information \(\mathcal{I}_t\):

\[
\max\;
\mathbb{E}\Bigl[
\sum_{\tau=t}^{t+H}
\bigl(R_{\mathrm{svc}} n^{\mathrm{svc}}_\tau - c_{\mathrm{travel}} d_\tau - P_{\mathrm{AU}} n^{\mathrm{AU}}_\tau\bigr)
+ V_f(x_{t+H},A_{t+H})
\Bigr]
\]

**First-stage (nonanticipative) decisions \(u_t\):** accept/reject on announced undecided requests; vehicle route certificate; first executable legs (travel/service/charge/wait).

**Recourse (scenario-dependent):** reoptimization after scenario revelations along each history, measurable w.r.t. the filtration generated by public events.

**Hard constraints:** stage-0 coverage of \(A_t\cup A^{\mathrm{new}}\); locks; public info only; terminal \((x_{t+H}^{(s)},A_{t+H}^{(s)})\in\mathcal{X}_f\) for every scenario \(s\).

**Soft:** economic objective only.

---

## 2. Implemented approximation (honest)

**Class:** restricted candidate-set stochastic MPC with scenario-dependent B1-validated recourse  
(`approximation_class` in code).

| Ideal object | Implementation |
|---|---|
| First-stage \(u_t\) | Discrete candidates from ALNS + heuristics + incumbent certificate |
| Shared scenarios | One scenario list scored for all candidates (nonanticipative first stage) |
| Recourse | `B1ValidatedRecourse` inside `expected_rollout_value` / `project_to_horizon` |
| Stage-0 hard | `validate_continuation` |
| Terminal hard | `project_to_horizon` → `verify_terminal_commitment` (distinct from stage-0) |
| Commit | Transactional `_try_commit` / `_emit_fallback` |
| Exact extensive-form MIP | **Not solved** |

**Feasibility:** preserved by independent validation + terminal filter + backup (E2), not by ALNS optimality.  
**Optimality:** only over the generated candidate set; no claim of global stochastic optimum.

ALNS is an **internal subroutine** for candidate generation / route repair.

## 3. Solver pseudocode

```
decide(o):
  C ← advance_or_invalidate(store); incumbent ← revalidate(C)
  U ← generate_candidates(ALNS, heuristics, incumbent)   # first-stage set
  Ξ ← sample_scenarios(o)                                 # shared, nonanticipative
  S0 ← ∅; scored ← ∅
  for u in U while budget remains:
      if not Validate(o, u): continue                     # stage-0 hard
      S0 ← S0 ∪ {u}
      if require_terminal:
          for ξ in Ξ:
              if not terminal_ok(project(o,u,ξ)): reject  # X_f hard (overrides)
      v ← E_ξ[causal_rollout(o,u,ξ)]                      # soft objective
      scored ← scored ∪ {(v,u)}
  u⁰ ← argmax_{u∈S0} greedy_nominal(u)   # Ulmer base = stage-0-matched GN
  û  ← argmax scored                     # CRN challenger (terminal pool)
  if FirstAction(û)=FirstAction(u⁰): u* ← u⁰
  else if E[J(û)−J(u⁰)] > δ_SPI and class(û) ⪰ class(u⁰)
       and (no extra accepts or û has terminal class): u* ← û
  else: u* ← u⁰                          # keep GN base (may be stage0 class)
  if try_commit(u*): return u*           # transactional
  return emit_fallback(incumbent)        # no new accepts
  apply only first action; re-solve at next event
```

## 4. Selection law (single; SPI default)

**One law:** Ulmer-style budgeted SPI over a **stage-0-matched** greedy-nominal first
action under **common random numbers**. The warm-start certificate is emission
fallback only — not the economic SPI base.

| Step | Rule |
|------|------|
| Stage-0 set | Same Validate survivors as CCE greedy-nominal (matched feasible first-action set) |
| Base \(u^0\) | \(\arg\max\) `greedy_nominal_value` on stage-0 set (tie-break: more accepts/services; certificate last). May emit with `feasibility_class=stage0` when empty-terminal is absent |
| Challenger \(\hat u\) | CRN / causal mean maximizer in the scored pool |
| Keep | Same first action+accepts, or CRN advantage \(\le \delta_{\mathrm{SPI}}\), or weaker class |
| Override | Advantage \(> \delta_{\mathrm{SPI}}\) **and** class ⪰ base; **extra accepts require hard terminal class** (not soft-glitch) |

**Frozen under `spi_mode=True`:** `forecast_override_margin`, `energy_gated_charge`.
**Forecast demoted** (proposed = empty future).

Feasibility classes (strongest → weakest among selectable): `stochastic_terminal` ≻
`nominal_terminal` ≻ `soft_terminal_glitch` ≻ `unchecked_budget` ≻ `stage0`.  
Soft plant/replay glitches **must not** be labeled `nominal_terminal`.

**Plant:** nonlinear piecewise charging only (`environment.energy`). Linear
\(g\cdot(target-soc)\) exists solely as a planning ablation (`LinearChargeEnergy`).

## 5. Terminal set \(\mathcal{X}_f\)

Implemented in `terminal_commitment.py`:

1. Simulate first action + B1 recourse toward \(t+H\).
2. `freeze_simulator_at_horizon`: advance clock to \(t+H\) with partial travel/charge locks.
3. Residuals from simulated observation: `accepted ∪ in_service − completed`.
4. `verify_terminal_commitment(terminal_state, residual, backup_routes)`.
5. Reject with reason ∈ `{terminal_infeasible, rollout_failed, replay_failed, budget}`.

Stage-0 Validate ≠ terminal membership (Gate 2 tests).  
Approximation: in-transit = origin node + proportional SoC (no continuous path state).

**Online guarantee:** certified-emission soundness only — see
`docs/proofs/RECURSIVE_FEASIBILITY_STOCHASTIC_MPC.md`. Unconditional RF withdrawn.
Theory claim stops at emission soundness + scenario-terminal honesty — **not** RF.

---

## 6. Receding horizon

Mandatory: solve → first action → observe → warm-start → re-solve.  
Certificate store publishes **only** the emitted certified decision.
